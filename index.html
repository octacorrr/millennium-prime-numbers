🔢 Millennium Prime Numbers

Exploración Computacional de la Conjetura de Riemann

Bienvenido al Proyecto

Este proyecto es una exploración computacional exhaustiva de números primos y de la famosa Conjetura de Riemann, uno de los problemas del Milenio más importantes en matemáticas.

El proyecto incluye implementaciones avanzadas de algoritmos para:

🔍 Pruebas de Primalidad

Miller-Rabin, AKS, Fermat, Solovay-Strassen

📊 Generación de Primos

Criba de Eratóstenes, Segmented Sieve, Atkin

📈 Análisis de Distribución

Teorema del Número Primo, Ley de Benford

🧮 Conjeturas Matemáticas

Goldbach, Primos Gemelos, Bertrand

ζ Función Zeta de Riemann

Cálculo numérico y verificación de ceros

📉 Visualizaciones

Gráficos interactivos con matplotlib

Características Principales

🎯 Módulos Especializados

  • primality_tests.py - Pruebas de primalidad avanzadas
  • prime_generation.py - Generación eficiente de primos
  • distribution_analysis.py - Análisis estadístico
  • conjectures.py - Verificación de conjeturas
  • riemann_zeta.py - Función Zeta de Riemann
  • visualization.py - Generación de gráficos

🚀 Algoritmos Implementados

  • Miller-Rabin (O(k log³ n))
  • Criba de Eratóstenes (O(n log log n))
  • Criba de Atkin (O(n / log log n))
  • AKS (determinístico, O(n⁶))
  • Lucas-Lehmer (primos de Mersenne)
  • Ecuación funcional de Riemann

📚 Conjeturas Verificadas

  • Conjetura de Goldbach
  • Conjetura de los Primos Gemelos
  • Postulado de Bertrand
  • Conjetura de Legendre
  • Conjetura de Cramér
  • Conjetura de Riemann (parcialmente)

🚀 Como Usar

Instalación

git clone https://github.com/octacorrr/millennium-prime-numbers.git cd millennium-prime-numbers pip install -r requirements.txt

Ejecutar el Programa Principal

python main.py

Generar Gráficos

python -c "from src.visualization import PrimeVisualizer; PrimeVisualizer.generate_all_charts(10000)"

Usar como Librería

from src.prime_generation import PrimeGenerator from src.primality_tests import PrimalityTester # Generar primos primes = PrimeGenerator.sieve_of_eratosthenes(1000) # Probar primalidad is_prime = PrimalityTester.miller_rabin(1009)
