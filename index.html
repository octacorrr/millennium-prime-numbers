🔢 Millennium Prime Numbers

Exploración Computacional de la Conjetura de Riemann

Bienvenido al Proyecto

Proyecto de exploración computacional de números primos y de la Conjetura de Riemann, uno de los siete problemas del Milenio del Clay Mathematics Institute.

Incluye implementaciones de algoritmos clásicos y modernos para primalidad, generación de primos, análisis de distribución, verificación de conjeturas y cálculo numérico de la función zeta de Riemann.

🔍 Pruebas de Primalidad

Miller-Rabin, AKS, Fermat, Solovay-Strassen, Lucas-Lehmer

📊 Generación de Primos

Criba de Eratóstenes, Atkin, Segmented Sieve

📈 Análisis de Distribución

π(n), Teorema del Número Primo, Ley de Benford

🧮 Conjeturas

Goldbach, Primos Gemelos, Bertrand, Legendre

ζ Función Zeta

Cálculo numérico, ceros en la línea crítica, verificación RH

📉 Visualizaciones

Gráficos de distribución, gaps, Goldbach y más

🚀 Cómo usar

Instalación

git clone https://github.com/octacorrr/millennium-prime-numbers.git cd millennium-prime-numbers pip install -r requirements.txt

Programa interactivo

python main.py

Función Zeta de Riemann

from src.riemann_zeta import RiemannZeta # ζ(2) ≈ π²/6 print(RiemannZeta.zeta(2)) # Buscar ceros en la línea crítica zeros = RiemannZeta.find_zeros_on_critical_line(0.1, 40, 0.15) print(zeros[:5])

Como librería

from src.prime_generation import PrimeGenerator from src.primality_tests import PrimalityTester primes = PrimeGenerator.sieve_of_eratosthenes(1000) is_prime = PrimalityTester.miller_rabin(1009)
